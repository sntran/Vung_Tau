# Vũng Tàu

Vũng Tàu is a 3D game about Vietnamese food and daily life. The player stays at a family homestay in a small hẻm in Vũng Tàu. The player learns how people in Vietnam really eat, order, and live around food.

The game is for Android and iPhone. It uses the Godot engine.
